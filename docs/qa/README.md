# Zkoušky v prohlížeči (19. 11. 2026)

Skripty pro Playwright, kterými vznikly snímky a nálezy v `docs/SHELL_HODNOCENI.md`. Čekají hru na http://127.0.0.1:8791 (`cd zdroje && npx vite --host 127.0.0.1 --port 8791`). Cesty k Playwrightu a k výstupům jsou z pracovního stroje a je třeba je upravit.

- `shots.cjs`: snímky menu, nastavení, nápovědy, Vývojáře, běhu, pauzy a háje na počítači a telefonu.
- `probe.cjs`: telefon na šířku (poloha položek), fokus a Enter, ukládání, poškozené úložiště, Esc.
- `tex.cjs`: snímek běhu po výměně textur (2.7.1).
